# 🏥 MediTrack – Technical Intervention Management System

MediTrack is a web-based frontend application designed to simplify the management and tracking of technical interventions.

The project aims to provide an organized interface for managing technical incidents, interventions, and technicians.

## ✨ Main Modules

- **Dashboard:** Overview of the application.
- **Interventions Management:** View and manage technical interventions.
- **Technicians Management:** Manage technician information.
- **Breakdowns Management:** Organize and track reported technical problems.

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Node.js and npm (development environment)

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/nadatouati96-cloud/MediTrack-Frontend.git
```

2. Navigate to the project directory:

```bash
cd MediTrack-Frontend
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm start
```

5. Open your browser at:

```text
http://localhost:3000
```
